# Day 04 — Python Quiz Game 🧠

A simple interactive quiz game built using Python. It asks tech-related questions about Python and checks the user's answers one by one.

## 🚀 Features

- 5 multiple-choice questions about Python.
- Displays four options for each question.
- Checks answers instantly.
- Tracks the score for correct answers.
- Displays the final score and a performance message.

## 🛠️ Concepts Used

- Lists and dictionaries
- `for` loops and nested loops
- `if`, `elif`, and `else` conditions
- User input using `input()`
- String methods: `.strip()` and `.upper()`
- Score counting using `score += 1`
- `len()` function

## ▶️ How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Run the following command in the terminal:

   ```bash
   python day_04_quiz_game.py
   ```

4. Enter A, B, C, or D for each question.

## 📚 What I Learned

In this project, I learned how to use a list containing dictionaries to store questions, options, and answers. I also practiced nested loops, conditions, and score counting. The most important thing I learned was how to take input after each question so the quiz runs one question at a time.
